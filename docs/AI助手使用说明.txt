==========================================================
   AI 助手 · 使用说明
   （网页版 AI，本机模型推理，云端中转）
==========================================================

一、这是什么
----------------------------------------------------------

一个网页版 AI 助手。你在浏览器里提问，问题经由云服务器中转，送到
运行着本程序的那台 Windows 电脑上，用本机的大模型算出答案，再实时
（边算边出字）传回网页。

    浏览器 ──► 云服务器 1.117.113.68 ──► 本机（跑模型）──► 答案返回

好处：
  · 本机不需要公网 IP，不用在路由器上开端口
  · 模型和数据都在自己电脑上，不上传对话内容
  · 任何一台装了本程序的电脑都能应答同一个网址


二、安装（一条命令）
----------------------------------------------------------

在任意一台 Windows 10/11 电脑上，打开 PowerShell（不用管理员），
粘贴这一行命令并回车：

    irm http://1.117.113.68/dl/i.ps1 -Headers @{Host='c-learning.oprfin.com'} | iex

它会自动完成 5 个步骤：

  1/5  下载安装包 ai.zip（约 1.1 GB，一个文件包含全部组件）
  2/5  解压到 C:\Users\<你的用户名>\AI助手\
  3/5  检查 Python：没有就自动静默安装（安装包已含在 zip 里）
  4/5  把安装目录加入用户 PATH（不需要管理员权限）
  5/5  启动全部服务，并自动打开浏览器

下载速度取决于网络，一般 2~8 分钟。


三、日常使用
----------------------------------------------------------

安装完成后，在「任意目录」打开命令行（cmd 或 PowerShell），输入：

    ai run        启动全部服务并打开网页（最常用）
    ai stop       停止全部服务
    ai status     查看各服务是否在运行
    ai chat       只打开对话版网页
    ai agent      只打开动手版网页
    ai where      显示安装目录

注意：新装的电脑需要新开一个命令行窗口，PATH 才会生效。


四、三个访问地址
----------------------------------------------------------

  对话版   http://127.0.0.1:8091
           问问题、查资料、聊天。回答边生成边显示（打字机效果）。
           会自动从本机的资料库里检索相关段落辅助回答。

  动手版   http://127.0.0.1:8092
           能真正修改文件、运行程序、看结果、再判断。
           只操作安装目录下的 workspace 子目录，改文件前自动备份 .bak。

  云端入口 http://c-learning.oprfin.com/
           外网可访问的同一个助手。任何一台装了本程序的电脑在线，
           就能应答这个网址；换电脑不用改网址。

  说明：云端入口依赖域名解析。如果打不开，用「管理员 PowerShell」
  执行一次下面的命令，把域名指向服务器即可（只对本机生效）：

      Add-Content C:\Windows\System32\drivers\etc\hosts "1.117.113.68 c-learning.oprfin.com"


五、动手版怎么用
----------------------------------------------------------

1. 打开 http://127.0.0.1:8092
2. 把要改的代码文件放进 C:\Users\<你>\AI助手\workspace\
3. 用自然语言提要求，例如：
     「把 demo.py 里打印次数从 3 次改成 1 次，然后运行验证」
     「给 xxx.py 加一个 main 函数，跑一下看有没有报错」
     「xxx.py 运行报错了，帮我修好并验证」
4. 它会依次做：读文件 → 生成修改后的内容 → 写回（原文件存 .bak）
   → 运行验证 → 告诉你结果

判定是否成功看「退出码」：0 表示运行正常；非 0 会明确告诉你失败。
如果模型没有真正改动文件，也会直接说明「文件没有实际改动」，不会假装成功。


六、配置（config.json）
----------------------------------------------------------

安装目录里的 config.json 可以调整：

    server            云端地址，默认 http://1.117.113.68:80
    host_header       走 nginx 用的域名，默认 c-learning.oprfin.com
    token             访问令牌，必须和服务器一致
    llama_url         本机模型地址，默认 http://127.0.0.1:8080
    llama_bin         llama-server 路径（留空=自动查找安装目录）
    model_path        模型文件路径（留空=自动查找 model.gguf）
    threads           CPU 线程数，默认 8
    max_new           单次最多生成多少 token，默认 400
    corpus            可选资料库路径，填了会在回答前检索
    auto_start_model  是否允许 worker 自动拉起模型（默认 true）

改完保存，执行 ai stop 然后 ai run 生效。


七、目录里有什么
----------------------------------------------------------

    ai.cmd / ai.ps1        ai 命令本体
    worker.py              连接云端、领任务、回传结果
    serve_r1.py            对话服务（8091）
    agent_r1.py            动手版服务（8092）
    chat.html              网页界面
    llama-server.exe       模型推理程序（17 MB）
    model.gguf             DeepSeek-R1-Distill-Qwen-1.5B 4bit 模型（1.07 GB）
    python-3.12.10-amd64.exe  Python 安装包（缺失时自动安装用）
    config.json            配置
    workspace\             动手版的工作目录
    sessions\              对话记录
    logs\                  各服务的运行日志


八、常见问题
----------------------------------------------------------

Q: 网页提示「超时：本地电脑没有响应」
A: 本机的 worker 没在跑。执行 ai status 看一下，再执行 ai run。

Q: ai 命令提示「不是内部或外部命令」
A: PATH 还没生效。新开一个命令行窗口；仍不行就检查：
   echo %PATH% 里是否有 ...\AI助手

Q: 网页打不开（域名）
A: 域名还没解析。按第三节执行 hosts 命令，或在域名后台加 A 记录：
   主机记录 c-learning，类型 A，值 1.117.113.68

Q: 回答很慢（10~20 秒）
A: 正常。1.5B 模型在 CPU 上就是这个速度，有 NVIDIA 显卡可以改用 GPU 加速。

Q: 端口被占用 / 服务起不来
A: 执行 ai stop 再 ai run。若仍冲突，看 logs\ 下对应 .err 文件的报错。

Q: 想换模型
A: 把新的 .gguf 放到安装目录（改名为 model.gguf 或改 config.json 的
   model_path），执行 ai stop 再 ai run。
